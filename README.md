# Portfolio (v1) — Retired

My first portfolio website. Built with vanilla HTML, CSS, and JavaScript with Bootstrap. Now retired in favor of a [Next.js rebuild](https://github.com/KULDUDECS50/portfolio-2.0), but keeping it around because it documents my earlier projects and has some nice nostalgia value.

## What It Was

A multi-page portfolio site with scroll animations, a typewriter hero section, parallax effects, a testimonial carousel, and a contact form. Featured projects from 2022-2023 including hackathon wins and published work.

## Featured Projects (at the time)

- **PoliticianWatch** — Won the Anti-Corruption category at MEGA Hackathon 2023.
- **API Terminology Handbook** — A 42-page reference guide published on Amazon covering API concepts and terminology.
- **Huey** — A Chrome extension color picker tool.
- **barter.** — A cryptocurrency trading application.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Structure | HTML5 |
| Styling | CSS3, Bootstrap 5 |
| Animation | AOS (Animate on Scroll), Typed.js |
| Carousel | OwlCarousel |
| Contact Form | FormSubmit |
| Interactivity | jQuery, Vanilla JavaScript |

## Why It's Retired

Outgrew it. Wanted server-side rendering, better performance, a real contact form (not a third-party redirect), and animations that felt more intentional. The [current portfolio](https://github.com/KULDUDECS50/portfolio-2.0) handles all of that.
